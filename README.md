# css-frameworks-CA

## Description
A framework assignment where i test out tailwind css. 
On index.html: login or register to get access to your own profile page (hardcoded)
On /profiles/index.html: See your own premade account
On /feed/index.html: See three pre-made posts where you can simulate adding a new post (won't be saved)
On /profiles/seeProfile.html: Check out a pre-made account for the top post (only accessable thorugh the first post.
click on the username belonging to the post). A follow/unfollow simulation is added thorugh a button (resets when leaving page as nothing is saved)

Enjoy the light and dark mode which is toggable on all pages. Even a logout function is added to redirect you back to the authentication page.

pages are responsive by using a width of 640px as the smallest width (from tailwind css standards)

## Technologies used
- HTML
- Tailwind CSS
- JS

## Available commands
- npm run dev
- npm run build
